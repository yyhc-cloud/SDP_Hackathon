1. Methodology 
- language/framework: flutter (mobile app)
- backend: supabase (for now maybe no need a proper a backend)

2. idea:
- community app that combine both resident + mall visitor

3. features:
- Physical recycling and food waste collection centre, when neighbors recycle or dump their food waste at the centre, they get some points as reward, that points could be used to pay parking fee in sime darby mall. For landed resident, the SDP can ask someone to collect the waste by resident request, as a result residents will get the points as reward. (recycling can come weekly, food waste collector daily based on request of residents) -> gamification
When a user throws an item into the bin, an integrated high-speed camera and acoustic sensor instantly analyze the item's visual features and the sound it makes upon dropping. If the user throws plastic into an organic bin or paper into a general waste slot, the internal baffle automatically redirects the item into the correct compartment while displaying an instant educational graphic on an outer screen.
-> report function for user to report there is waste for collect
-> AI scanner to instantly detect the waste user put in, and reward the points
-> gamification (leaderboard, streaks, guild wars) 
-> points will be used for paying parking fee
-> basic style/theme of the app
